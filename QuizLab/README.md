# QuizLab

Projeto de quiz por área de conhecimento.

## O que tem nesta versão

- Layout moderno e responsivo.
- 10 perguntas de Geografia.
- 10 perguntas de História.
- 10 perguntas de Artes.
- 10 perguntas de Ciências.
- Resultado ao final do quiz.
- Campo para salvar o nome do jogador depois da pontuação.
- Ranking salvo no navegador com `localStorage`.

## Como executar

Abra o `index.html` no navegador ou use a extensão Live Server no VS Code.
