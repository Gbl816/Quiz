## Problemas documentados

### 1. Teste completo das perguntas
Ainda é necessário testar todas as 10 perguntas para garantir que o usuário consiga responder o quiz inteiro e visualizar a pontuação final corretamente.

### 2. Responsividade no mobile
Apesar do layout responsivo ter sido planejado, ainda é necessário verificar se as três colunas realmente colapsam corretamente para uma coluna em telas menores.

### 3. Carregamento dos arquivos CSS
É necessário verificar no console do navegador se todos os arquivos CSS estão sendo carregados na ordem correta, principalmente os arquivos separados por arquitetura ITCSS.

### 4. Feedback visual
O projeto ainda pode melhorar o feedback visual após o usuário responder uma pergunta, deixando mais claro quando a resposta está correta ou incorreta.
